## Exact new archive contract

Use a separate envelope `format: 'family.unattributed-work.v1'`, `sha256` lowercase SHA-256 of the UTF-8 **payload string**, and that `payload` string. Do not reuse or reinterpret `family.original-work.v1`, v2 or v3.

Payload fields, in fixed emitted order:

1. `attribution: { kind: 'unattributed' }` — no inferred `source_owner`, source, Auth UUID, Family or Person assertions.
2. `device_origin` — browser origin only, explicitly not a Supabase source or identity guarantee.
3. `database: { name, indexeddb_version: 140 }` — locator/version observed during capture, no authorization meaning.
4. `captured_at` — ISO UTC capture time; `automatic_replay: false`.
5. `captured_stores: ['mutationQueue','importFiles']`, `excluded_stores` sorted names excluding those two (including syncMeta, which was checked, not exported).
6. `counts: { queue, imports }`; `graph` from the existing lossless encoder of `{ queue: [{ key, row }], imports: [{ key, row }] }` in primary-key cursor order.

Filename `family-unattributed-work-v1.json`, MIME application/json, size bounded after full envelope serialization too. Check cancellation after each async byte/digest step and immediately before the explicit final Download click. Require a preview/ready state before that final click; create/revoke the Blob URL with enough lifetime for the real browser download, clear all in-memory references on close/cancel. The source graph is never an executable API payload. Export does not sign, upload, replay, acknowledge, delete or mark completion. A successful download does not prove an independent backup or restoration. Do not label the work recovered into Family; say an unattributed local copy was exported.
