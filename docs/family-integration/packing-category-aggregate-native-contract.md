# U04-C3c2b — native packing category aggregate contract

This completes native composition for the accepted125 database and C3c2a SDK/queue. The separate TREK5.1.2 reconciliation branch retains native card markup/styles and the existing Family packing Trash dialog. No database migration is part of this packet.

Desktop captures the complete owned category lane at drag start, including retained empty categories and deterministic tied ranks. Native drag carries the stable category key rather than its display name. Open/Done and alphabetical selections cannot reorder a hidden subset. Personal ordering excludes foreign personal owners; unrelated item ranks and common/personal lanes are preserved. Phone has no upstream category drag control; it displays canonical order without an invented reorder widget.

A nonempty Delete List captures the exact rendered canonical category/item set, original scope/root/collection, category facts and one operation UUID at menu opening. Native desktop confirmation and phone confirmation show its actual name and count. Filtered status views cannot issue a whole-category delete. One aggregate command replaces child loops; category metadata keys cannot enter item effects. Old empty dismiss remains the explicitly observed v2 command, not a synthetic aggregate fallback.

Trash reads bind original pages and their complete manifests to the same publication. Batch children appear under their category, not as independently restorable item rows. If more category pages remain, independent item rows wait until membership is fully inspected. Each Restore uses that exact page/category/batch and a new deliberately allocated operation UUID. Legacy empty restores use their observed v2 domain. Earlier independently deleted items are not added to a batch. A torn page, changed category/count/collection/scope or copied/mutated page is refused before saving; names are never used to reconstruct membership.

Original bytes survive uncertain replies. Duplicate clicks share their flight and exact retry keeps the UUID and observation. Generic queue replay remains gated. Explicit receipt recovery validates the authentic commitment, removes only its matching original and refreshes the coupled canonical read. A confirmed original is then retired from its menu binding so a later deliberate operation can get a fresh UUID. Unknown receipts cannot retire originals or grant new authority. Permission, account/Person/Family/Trip/source/layer/read-only/disposal fences remain enforced. Acknowledged canonical redraws do not turn a committed operation back into an unresolved one.

Only `VITE_FAMILY_PACKING_AGGREGATE_QUALIFICATION=local-v3` with exactly `http://127.0.0.1:55731` activates this rehearsal through normal bootstrap. The125 preparation/public-variant branches require that same explicit qualification. Prior124 identity flags and earlier sources remain independent. Hosted/default activation, deployment and source publication still require the separate release process. Saved v1/v2/v3 parsers/bytes and cold read-only behavior are preserved. Stored variant objects remain required; no image transformations are introduced.

Unrelated bag management, sharing/contributors/clone, imports/templates and Tours remain on their earlier gates. This contract does not declare all packing or the full website production ready.
