# U04-C1c — native packing group controls contract

The existing TREK5.1.2 desktop/phone controls now support category Check All, Uncheck All, category Trash and whole-view clear-completed in the qualified Family cohort. All four labels use the three reviewed transactional group commands on unchanged disposable schema120. No hosted activation is implied.

Category menu opening captures source, authenticated user/Person/Family/Trip, planner layer/lifecycle, collection revision, exact original rendered members and raw labels. Common/personal view and current status filter bound category membership. Empty labels and a real category whose name matches the translated default remain distinct raw labels in one displayed category. Whole-view clear-completed instead observes every actor-visible member of the chosen view, including unchecked rows and regardless of status filter.

The parent owns each original above filtered category lifetime. Choosing an action creates one immutable operation and intent; repeated submit coalesces. Closing/reopening or a rerender cannot replace an uncertain original or choose a different action. Changed account, source, Trip, layer or owner refuses before a raw/optimistic effect. Generic queue replay continues skipping originals; explicit recovery inspects their genuine receipts first. Redacted commitment cannot publish private content or become replay authority.

Each qualified native action sends one group RPC, never item loops. Packed-state clears partial counts explicitly, no-op members stay in the complete observation, category Trash respects the active filtered set, and clear-completed preserves unchecked rows. Canonical rows, relationships and authoritative ancillary totals use the existing guarded publication. Whole-group Restore remains unavailable; the existing observed individual Trash-page Restore preserves each identity.

The global legacy group gate stays closed. Rename, assignees, bags, sharing/contributors/clone, imports/templates and whole-group Restore remain separate. Ordinary TREK writers outside Family retain their existing behavior. Native layout/styles are preserved. One desktop event hook captures menu geometry at click time instead of reading a possibly detached ref during render; real browser testing exposed the old menu appearing underneath navigation after a save.

Pending commands deliberately pause native authoring. A successful acknowledgement is not permission: the actual guarded reader must revalidate. Browser acceptance covers the existing Try again action when a racing passive refresh leaves the boundary paused. A genuine committed response loss survives reload and resolves from its original receipt without another group execution. Cold saved reads expose neither item nor group authoring.

Validation uses native components/events, real local SDK/Auth/TOTP/PostgREST, and the ordinary App plus generated worker. Hosted origins and every image transformation path are blocked at the browser proxy before forwarding, including worker-owned requests. No schema/dependency/production/preview/settings/billing/media/backfill/backup/ETL change belongs to this packet.
